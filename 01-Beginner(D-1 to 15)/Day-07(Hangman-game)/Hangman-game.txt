Think of Hangman as a **game of hidden information**.


One side knows a secret word.
The other side must discover it using only **letter guesses** before running out of chances.

Let's build the entire game from first principles.

-----------------------------------------------------------------------

# 1. What is Hangman?

Hangman is a **word guessing game**.

The computer secretly chooses one word.

The player **cannot see the word**.

Instead, the player sees only blank spaces representing each letter.

Example:

Secret word: "PYTHON"
```

Player sees: _ _ _ _ _ _(blank spaces with respective blanks for the word)
```

The objective: It is to discover the entire word before making too many wrong guesses.

---

Once the full figure is completed, the player loses.

Today many games simply show "Lives Remaining: 6" instead of drawing the figure.

# 3. What are the rules?

Suppose the secret word is


ELEPHANT
```

Initially the player sees


_ _ _ _ _ _ _ _
```

The player guesses one letter.

Suppose they guess
E
```

Since E exists in the word, reveal **every E**.


E _ E _ _ _ _ _
```

Notice something important:

The player guessed **only one letter**.

But both E's became visible.

---

Now the player guesses
L
```

Result

```text

```

---

Player guesses

```text
Z
```

There is no Z.

Nothing changes.

Instead

* Wrong guesses increase by 1
* One life is lost

---

Continue until one of two things happens.

---

## Win

All letters become visible.

```text
E L E P H A N T
```

Player wins.

---

## Lose

Wrong guesses reach the maximum.

For example

```text
Maximum Wrong Guesses = 6

Wrong Guess = 6

Game Over
```

# 11. What variables are needed?

A basic Hangman program typically needs:

| Variable          | Purpose                                     |
| ----------------- | ------------------------------------------- |
| `secret_word`     | The hidden word selected by the computer    |
| `guessed_letters` | Letters the player has guessed correctly    |
| `wrong_letters`   | Incorrect guesses made by the player        |
| `wrong_guesses`   | Number of mistakes                          |
| `max_wrong`       | Maximum allowed mistakes (e.g., 6)          |
| `category`        | The chosen category (Animals, Fruits, etc.) |

# 12. The core algorithm (without Python syntax)

The entire game can be described in plain English:

```
START

Choose a category.

Choose one random word from that category.

Store it as the secret word.

Set wrong guesses to zero.

Create an empty list of guessed letters.

WHILE game is not over

    Display the hidden word.

    Ask the player for one letter.

    IF the letter was already guessed

        Tell the player.

        Continue.

    IF the letter exists in the secret word

        Save it as a correct guess.

    ELSE

        Increase wrong guesses.

    IF every unique letter in the secret word has been guessed

        Player wins.

        Stop.

    IF wrong guesses equal the maximum allowed

        Player loses.

        Reveal the word.

        Stop.

END
```

# 13. Programming concepts you'll practice

Hangman is a favorite beginner Python project because it combines many core concepts:

* **Variables**: store the secret word, guesses, and lives.
* **Lists or sets**: track guessed letters.
* **Strings**: represent and examine the secret word.
* **Loops (`while`)**: keep the game running until it ends.
* **Conditionals (`if` / `else`)**: determine whether a guess is correct.
* **Functions**: organize tasks like displaying the word or checking for a win.
* **Random selection**: choose a word from a list.

---

## The big idea

From a programming perspective, Hangman is **not about drawing a stick figure**. It's about **maintaining and updating the game's state**.

At any moment, the game is fully defined by:

* the **secret word**,
* the **letters guessed so far**, and
* the **number of wrong guesses**.

Every time the player enters a letter, your program updates that state according to a few simple rules, displays the new state, and repeats until the player either reveals the entire word or runs out of lives. That's the complete logic behind Hangman.

To understand **leap years**, you first need to understand **how long Earth actually takes to go around the Sun**.

---

# Step 1: The Problem

We usually say

```
1 Year = 365 Days
```

But this is **not exactly true**.

The Earth actually takes approximately

```
365.2422 days
```

to complete one orbit around the Sun.

That means every year we ignore

```
365.2422
-365
---------
0.2422 day
```

Every year, our calendar falls behind the Earth's position by about **0.2422 days** (about **5 hours 49 minutes**).

---

# Step 2: What happens after 4 years?

Each year we lose

```
0.2422 day
```

After 4 years

```
0.2422 × 4

= 0.9688 day
```

That's almost

```
1 day
```

If we didn't fix this, after a few decades, the calendar would drift noticeably. Over centuries, seasons would no longer line up with the same months.

So every **4 years**, we add **one extra day**.

```
February

28 days

↓

29 days
```

That year has

```
366 days
```

instead of

```
365 days
```

This is called a **Leap Year** because the calendar "leaps" ahead by one day to catch up.

---

# Step 3: But there's a small problem

Adding one day every 4 years assumes the extra time is exactly

```
0.25 day
```

because

```
1 day ÷ 4 years

= 0.25 day/year
```

But the real extra time is

```
0.2422 day/year
```

Difference

```
0.2500
-0.2422
---------
0.0078 day/year
```

We're adding **slightly too much** every year.

That tiny error builds up over centuries.

---

# Step 4: Century Years

Consider

```

1800
1900
2000
2100
2200
```

If every multiple of 4 were a leap year, we'd add too many leap days over long periods.

So we make an exception:

**Years divisible by 100 are NOT leap years.**

That means:

```
1700 ❌

1800 ❌

1900 ❌

2100 ❌
```

---

# Step 5: But another problem!

Now we've removed **too many** leap days.

So we need another correction.

If the century year is also divisible by **400**, then it **is** a leap year.

Examples:

```
1600 ✅

2000 ✅

2400 ✅
```

---

# Final Mathematical Rules

A year is a leap year if:

### Rule 1

Divisible by 4

```
Year % 4 == 0
```

Example

```
2024

2024 ÷ 4 = 506

No remainder

Leap Year
```

---

### Rule 2

If divisible by 100

```
Year % 100 == 0
```

then it is **NOT** a leap year.

Example

```
1900

1900 % 100 = 0

Not Leap Year
```

---

### Rule 3

Unless divisible by 400

```
Year % 400 == 0
```

Example

```
2000

2000 % 400 = 0

Leap Year
```

```python
if year % 4 == 0:
    if year % 100 == 0:

else:
    print("Not Leap Year")
```

## The idea to remember

A **leap year** exists because the Earth does **not** orbit the Sun in exactly **365 days**—it takes about **365.2422 days**. The calendar compensates for this by adding an extra day every four years, but because `0.2422` is slightly less than `0.25`, additional century rules (100 and 400) keep the calendar aligned with the Earth's orbit over hundreds of years.

## One small correction to your reasoning

You said:

> "In a century 25 times we add one day."

That's true **if** every year divisible by 4 were a leap year. But in the Gregorian calendar, century years are special. For example, from **1901 to 2000**, the leap years would normally be 1904, 1908, ..., 1996, **and 2000**. There are 25 multiples of 4 in that range, but the century rule decides whether the century year counts. **1900** was **not** a leap year, while **2000** **was** because it is divisible by 400.

The calendar rules are designed so that over a **400-year cycle** there are **97 leap years** (not 100). That gives an average year length of:

```
365 + 97/400
= 365.2425 days
```

The true tropical year is about:

```
365.2422 days
```

So the Gregorian calendar differs by only about **0.0003 day per year** (about **26 seconds per year**), which means it takes roughly **3,300 years** for the calendar to drift by about one day. That's why these seemingly complicated rules work so well—they're a carefully engineered approximation of the Earth's actual orbit.
